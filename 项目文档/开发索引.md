# 开发索引

本文件用于跨模块改造或需要项目全貌时按需查阅。日常任务从根目录 `AGENTS.md` 的任务索引直接进入代码，不需要先读本文件。

## 产品与数据边界

- 项目是 Windows 上运行的本地照片回忆库，照片、缩略图、数据库和标签都属于敏感本地数据。
- 数据主链路：扫描文件 → `files` → 提取缩略图/EXIF/phash → `photo_metadata` → 分类、标签和回忆 → UI 展示。
- 所有照片默认有回忆价值。成人、写真、截图、生活照不是删除或排除状态；重复和损坏才是状态问题。
- 业务分类只有生活和样片。AI 识图可以生成标签及疑似样片候选，但不能自动把生活照改成样片。

## 当前前端结构

唯一界面入口是本地网页，`启动GPU相册.bat` 启动 `main.py web` 并打开系统浏览器。旧 PyQt 桌面端及其依赖已经移除。

| 模块 | 职责 | 性能约束 |
| --- | --- | --- |
| `webapp/server.py` | 本地 HTTP API、媒体响应、浏览器启动 | 只绑定 `127.0.0.1`；不向网页暴露真实文件路径 |
| `webapp/frontend/src/App.jsx` | 页面状态、查询缓存、分类与批量复核 | TanStack Query 管理异步缓存和失效，不手写全局请求状态机 |
| `PhotoMasonry.jsx` | 虚拟瀑布流、懒加载、Shift 选择 | 使用 Virtuoso Masonry，只渲染可视区域 |
| `PhotoLightbox.jsx` | 大图、相邻预加载、缩放、全屏和键盘操作 | 使用 Yet Another React Lightbox，不重复实现焦点与轮播控制 |
| `AppNavigation.jsx` | 桌面侧栏和移动端底部导航 | 使用 MUI 响应式组件与无障碍语义 |
| `business/recommendation.py` | 分类查询、随机抽取、文件夹/时间打散、跨页去重 | 有界候选集；避免全库 `ORDER BY RANDOM()` 和重复查询 |
| `webapp/` | 唯一本地网页界面、媒体服务和热启动缓存 | 保持虚拟瀑布流、预加载和查询缓存 |

网页依赖由 pnpm 构建后写入 `webapp/static/`，运行时不访问 CDN。前端调整可以改变布局、导航和交互，但业务查询、分类优先级和数据库写入必须继续留在 Python 服务层。

## 后端模块定位

- `business/indexer/`：索引照片、生成元数据和缩略图；worker 可并行读图，SQLite 写入串行。
- `business/classifier/`：生活/样片规则、文件夹分类、单张覆盖和疑似样片复核。
- `business/image_recognition/`：SigLIP 标签生成及阈值校准。
- `business/memory/`：回忆发现与反馈，不等于简单标签分组。
- `infra/image/`：缩略图、模型编码和图像基础设施。
- `infra/db/repositories/`：数据库访问封装。
- `services/`：后台任务、设备和生命周期协调。

## 关键数据表

- `files`：文件路径、类型和路径状态。
- `photo_metadata`：缩略图、日期、尺寸、phash、重复关系、单张分类。
- `folder_categories`：文件夹分类结果。
- `photo_tags`：`path`、`siglip`、`manual` 等来源标签。
- `photo_tag_status`：版本化识别状态，用于增量重跑。
- `photo_shown_history` / `click_history`：展示和点击历史。
- `memories` / `events`：可再生回忆和事件数据。
- `task_checkpoints`：长任务断点。

`file_id` 不是跨库重建后的稳定外部标识；重建数据库后，回忆、标签和事件引用需要重新生成或审计。

## 已建立的体验基线

- 冷启动：页面先显示骨架/已有缓存，索引、时间线、回忆和标签任务后台启动。
- 热启动：复用分类结果、缩略图内存缓存和已经渲染的页面，数据版本变化后再刷新。
- 滚动：瀑布流虚拟化；缩略图按可视区优先加载并预取上下缓冲区。
- 随机浏览：候选有界，按文件夹、日期和相邻上下文打散，跨页按 ID/phash 视觉键去重。
- 图片查看：当前图片异步加载，相邻图片预加载，关闭或快速切换时忽略过期回调。

这些属于回归基线。前端改造后至少验证：首次打开、返回已打开页面、连续滚动、快速切换分类、连续查看相邻图片和退出时 worker 回收。

## 本地 AI 规则

- SigLIP 是可选增强，不阻塞基础浏览。
- 模型与 tokenizer 只从本地 Hugging Face 缓存解析；缺失时明确不可用，不联网下载。
- 当前成人识别使用 `siglip-v3-nsfw` 状态版本，核心标签包括 NSFW、裸体、露骨内容和明确裸露部位。
- 弱风格标签如写真、模特、内衣不能单独触发疑似样片。
- 新版校准结果带 `nsfw-review:calibrated-v3`；旧标签逐张成功重跑后替换。

## 常用验证

```powershell
$env:PYTHONPATH=(Resolve-Path '.venv311\Lib\site-packages').Path
python -m pytest -q
python -m py_compile main.py webapp\server.py webapp\hot_cache.py business\recommendation.py
cd webapp\frontend
pnpm run build
```

真实库验证默认只读、小批量。不要从文档指令推导出全量扫描、全量识别或数据库写入授权。
