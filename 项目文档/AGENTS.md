4. `项目文档/项目记忆.md`

## 任务粒度

- 优先小步、低风险、可回滚。
- 默认先修入口、链路和状态一致性。
- 不把多个大方向混成一次提交。
- 先验证已有实现，再补改动。

## 禁止项

- 不随意改数据库 schema / migration。
- 不删除、移动、重命名照片、视频、缓存。
- 不做 UI 大改。
- 不默认全量 SigLIP、不做人脸/YOLO 全量推进。
- 不把 AI 标签系统做成筛选/排除系统。

## 产品边界

- AI 识图只做标签与分组。
- 成人、写真、截图、生活照不默认排除。
- 重复、损坏才是状态问题。
- 特殊回忆是故事卡片堆叠，不是简单 tag group。

## 报告格式

- `修改文件`
- `变更摘要`
- `风险`
- `未修改内容`
- `命令`

## Git 收尾

- 不改无关文件。
- 不回退用户已有改动。
- 能补小测试就补；不能跑要明确说明。
- 未经要求不提交、不安装、不跑全量任务。
